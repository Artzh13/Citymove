# Специфікація Предметної Моделі (Спринт 1)

Цей розділ описує всі класи, їхні поля, методи та ієрархію винятків першого спринту, щоб інші модулі (парсер та алгоритм пошуку) знали, як правильно взаємодіяти з даними.

## 1. Базові сутності (Класи)

**Зупинка (Stop)**
- `stop_id` (str) — унікальний ідентифікатор (лише для читання).
- `name` (str) — назва зупинки (не може бути порожньою).
- `lat` (float) — широта (від -90.0 до 90.0).
- `lon` (float) — довгота (від -180.0 до 180.0).

**Маршрут (Route)**
- `route_id` (str) — унікальний технічний ідентифікатор.
- `short_name` (str) — короткий номер маршруту для виводу користувачу (наприклад, "114", "3").
- `transport` (об'єкт класу TransportUnit) — тип транспорту, що обслуговує маршрут.
- `stops` (list[str]) — список зберігає лише ID зупинок (рядки) без повторень у порядку проходження.

**Рейс (Trip)**
- `trip_id` (str) — унікальний номер рейсу.
- `route` (об'єкт класу Route) — маршрут, за яким виконується рейс.
- `start_time` (int) — загальний час відправлення (у хвилинах від опівночі).
- `service_id` (str) — ідентифікатор днів курсування (будні/вихідні) для фільтрації розкладу.
- `stop_times` (list[tuple[str, int, int]]) — детальний розклад руху зупинками. Формат кортежу: `(stop_id, arrival_min, departure_min)`. Усі часові мітки зберігаються у хвилинах.

**Пасажир (Passenger)**
- `passenger_id` (str) — ідентифікатор пасажира.
- `name` (str) — ім'я (за замовчуванням "Unknown", не може бути порожнім).

## 2. Ієрархія Транспорту

**Базовий абстрактний клас: TransportUnit**
- `speed` (float) — швидкість (км/год).
- `capacity` (int) — місткість.
- `fare` (float) — вартість проїзду.
- `name()` — абстрактний метод, що повертає назву виду транспорту рядком.

**Нащадки:** `Bus`, `Tram`, `Trolleybus`, `Metro`.
*Контракт створення:* Парсер не вираховує і не передає ці параметри при створенні об'єктів. Швидкість, місткість та вартість проїзду є різними для кожного виду і жорстко зашиті всередині конструкторів кожного класу-нащадка.

## 3. Мережа (Network)

Клас `Network` виступає як головний контейнер-агрегат транспортної системи.

**Поля:**
- `stops` (dict[str, Stop]) — словник об'єктів зупинок (ключ: `stop_id`).
- `routes` (dict[str, Route]) — словник об'єктів маршрутів (ключ: `route_id`).
- `trips` (dict[str, Trip]) — словник об'єктів рейсів (ключ: `trip_id`).
- `transfer_time` (int) — час, необхідний на пересадку між різними рейсами (за замовчуванням 5 хвилин).
- `edges` (dict[str, list[tuple]]) — зважений список суміжності графа для алгоритму Дейкстри. 
  *Формат:* `{from_stop_id: [(to_stop_id, departure_min, travel_min, trip_id), ...]}`. Алгоритм використовує зміну `trip_id` у сусідніх ребрах для ідентифікації пересадки та додавання `transfer_time`.

## 4. Ієрархія Винятків

Всі власні помилки предметної області наслідуються від базового класу **NetworkError**. Інші модулі повинні перехоплювати їх у разі проблем:
- `NetworkError` — базовий клас помилки мережі.
- `StopNotFoundError` — підіймається, якщо запитаної зупинки немає в мережі.
- `RouteNotFoundError` — підіймається, якщо не знайдено маршрут.
- `DisconnectedNetworkError` — підіймається, якщо порушується зв'язність графа (наприклад, при видаленні критичного вузла).
- `ScheduleError` — помилки, пов'язані з некоректним розкладом чи відсутністю рейсів.
