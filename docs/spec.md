# Специфікація взаємодії (Спринт 1)

Тут фіксуємо, як наші модулі спілкуються між собою, щоб нічого не зламалося при злитті коду.

## 1. Назви полів у класах (domain.py)
Щоб всі зверталися до змінних однаково:

Зупинка (Stop)
- stop_id (str) — айді
- name (str) — назва
- lat (float) — широта
- lon (float) — довгота

Маршрут (Route)
- route_id (str)
- transport (об'єкт класу TransportUnit)
- stops (list) — зберігаємо тільки список айдішників зупинок (наприклад ['s1', 's2']), самі об'єкти сюди не пхаємо.

## 2. Як Парсер (dataio.py) передає дані
Парсер сам об'єкти не створює. Він читає файл і віддає в domain.py просто список словників.
Формат для зупинок має бути строго такий:
[{"stop_id": "1", "name": "Центр", "lat": 49.8, "lon": 24.0}]

## 3. Як працюють Алгоритми (core.py)
Для графа потрібна інформація, хто з ким з'єднаний.
Клас Network матиме метод, який віддаватиме словник суміжності у форматі:
{"stop_id_1": ["stop_id_2", "stop_id_3"]}. 
Штраф за пересадку будемо передавати окремим параметром при виклику алгоритму.
