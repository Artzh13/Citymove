## Інструкція із запуску

Для локального розгортання проєкту та уникнення конфліктів версій необхідно використовувати віртуальне середовище.

1. Створення віртуального середовища (виконується в корені проєкту):
`python -m venv venv`

2. Активація віртуального середовища:
- Для Windows (у cmd):
`venv\Scripts\activate`

(Якщо використовується PowerShell, спочатку виконайте: `Set-ExecutionPolicy Unrestricted -Scope CurrentUser`)

- Для macOS / Linux:
`source venv/bin/activate`

3. Встановлення залежностей:
Переконайтеся, що в терміналі з'явився префікс `(venv)`, і виконайте:
`pip install -r requirements.txt`
